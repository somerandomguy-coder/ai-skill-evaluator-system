# 100 Job Descriptions Sourcing Guide for Australian Tech Ecosystem

This guide provides an actionable, step-by-step strategy to source and populate **100 real-world Job Descriptions (JDs)** across the Australian technology ecosystem. Populating these into our PostgreSQL requirement bank ensures **instant challenge generation, zero LLM research latency, and deep SFIA 9 alignment**.

---

## 1. LinkedIn & Seek Australia Search Architecture

### Recommended Search Filters
- **Platform**: LinkedIn Jobs / Seek.com.au
- **Location Filter**: `Australia` (or `Sydney`, `Melbourne`, `Brisbane`, `Remote Australia`)
- **Date Posted**: `Past Month` (ensures active modern tech stacks)
- **Experience Level**: `Associate` (SFIA Level 2) & `Mid-Senior level` (SFIA Level 3)

## 3. How to Ingest JDs Into the Database

### Method A: Add to `data/imported_jds.json`
Simply paste your copied JDs into `data/imported_jds.json`:

```json
[
  {
    "roleTitle": "Senior Full-Stack Engineer",
    "employer": "SafetyCulture",
    "domain": "Mobile Workplace Operations",
    "sourceUrl": "https://www.linkedin.com/jobs/view/...",
    "rawJd": "Pasted LinkedIn text here...",
    "mustHaveSkills": ["TypeScript", "React", "PostgreSQL"],
    "timeboxMinutes": 180
  }
]
```

### Method B: Run the Automated Population Command
Execute:
```bash
npm run db:populate
```
The script will:
1. Parse the JD and extract SFIA 9 skill codes (`PROG`, `DESN`, `TEST`, etc.).
2. Generate an Evidence-Centered Design (ECD) rubric with observable signals and failure modes.
3. Classify importance levels (`CRITICAL`, `CORE`, `STANDARD`).
4. Save directly into PostgreSQL for instant zero-latency retrieval!
