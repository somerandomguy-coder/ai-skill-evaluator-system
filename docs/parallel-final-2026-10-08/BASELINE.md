## Suspected risks requiring reproduction, not claimed findings

- Submission versus a late assistant write may still produce a transcript/snapshot mismatch: review the transaction boundaries and test two concurrent service invocations. A timestamp filter alone is not a frozen transcript manifest.
- Task version pinning and mentor audit invalidation across fresh server processes need a real disposable-DB test; schema fields and local repository tests are insufficient.
- Source truncation can omit a decisive middle requirement even though opening/tail are kept. Add adversarial cases and clarify/reject where coverage is insufficient.
- Preview isolation, session switching, package install hangs, SQLite resource cleanup and browser compatibility need real browser checks. An iframe alone is not a complete execution-boundary proof.
- Embedding dimension equality is not proof of the same provider/model/vector space. Keep experimental semantic lookup off the default generation path.
- Telemetry minimization is partly implemented and tested; inspect both explicit tracking and any SDK wrapper before claiming no raw candidate content leaves the service.
- Timing, hosting bottlenecks, cost per complete attempt and production fallback outcomes were not measured here. A Fly.io move alone does not resolve client runtime delays, duplicate dispatches, or model latency.
